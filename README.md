## 📁 Repository Structure & Projects Included

This repository features three distinct, fully responsive, and clean HTML5/CSS3 webpages built during my introductory web development learning journey:

1. **`01-portfolio.html` — Personal Portfolio Website**
   * *Description:* A personal landing page presenting my professional profile, technical skills, project showcase, educational background, and hobbies.
   * *Key Sections:* Hero Introduction, About Me, Technical Skills (Python, HTML, CSS), Project Showcase, Education Table, Beyond Coding (Interests), and My Vision.

2. **`02-college.html` — College Information & Admissions Website**
   * *Description:* An institutional webpage designed for DR. RVR NRI Institute of Technology, highlighting academic departments, campus facilities, events, and student life.
   * *Key Sections:* Institutional Header, Navigation Bar, Hero Welcome Banner, Quick Stats, About Our College, Departments & Courses (CSE, CSM, Electronics), Campus Facilities, Events, and an Interactive **Student Enquiry Form**.

3. **`03-student.html` — Student Academic Dashboard**
   * *Description:* A comprehensive student portal and dashboard displaying semester overview metrics, profile details, subject-wise internal marks, attendance reports, assignment tracking, class timetables, and academic notices.
   * *Key Sections:* Welcome Banner, Overview Cards (Subjects, Attendance, Marks, Assignments), Student Profile Grid, Subject Grid, Marks Report Table, Attendance Report Table, Assignments Tracker with Status Badges, Class Period Timetable, and Notices & Reminders.
